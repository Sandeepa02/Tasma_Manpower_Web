A modern manpower management platform designed to streamline hiring, staffing, and workforce coordination for businesses and job seekers. `Tasma Manpower Web` brings together recruitment workflows, talent discovery, and operational visibility in one clean and efficient digital experience.

---

## Why This Project Matters

In today’s fast-moving job market, companies need a smarter, faster, and more transparent way to hire and manage manpower. This project aims to provide:

- Faster candidate discovery and screening
- Cleaner staffing workflows for employers
- Better communication between recruiters and applicants
- A scalable base for manpower and workforce management

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js 18+
- npm or yarn
- Git

### Installation

```bash
git clone https://github.com/Sandeepa02/Tasma_Manpower_Web.git
cd Tasma_Manpower_Web
npm install
```

### Run the App

```bash
npm run dev
```

Then open the app in your browser at:

```bash
http://localhost:3000
```
